운동 루틴 체크

 

이 브라우저에서는 자동 저장이 되지 않습니다. 시크릿/사생활 보호 창이거나, 사이트 데이터가 차단되어 있거나, 브라우저 종료 시 데이터를 지우도록 설정되어 있을 수 있습니다. 아이폰이라면 파일 앱에서 바로 열지 말고 사파리로 열어 주세요. 일반 창에서 열거나, 아래 백업 저장으로 파일을 받아 다음에 백업 불러오기로 이어서 쓰세요.

다른 컴퓨터로 기록 옮기기

보내는 컴퓨터 — 아래 칸의 코드를 [코드 복사]로 복사해, 메신저나 메모에 붙여 두세요.
받는 컴퓨터 — 그 코드를 아래 칸에 붙여넣고 [붙여넣은 코드 적용]을 누르세요.

 

코드에는 계획과 실제 기록만 담겨 있습니다. 파일을 옮기기 어려울 때 쓰세요. 기록이 많으면 코드가 길어지므로, 그럴 때는 [백업 저장]으로 파일을 옮기는 편이 편합니다.
운동 설정(이름·목표)은 코드에 담기지 않습니다. 받는 쪽의 운동 순서가 다르면 기록이 엉뚱한 운동에 붙으므로, 설정까지 함께 옮기려면 [백업 저장] 파일을 쓰세요.

기록은 사용자 이름별로 나뉘어 이 브라우저에 자동 저장됩니다. 위쪽 운동 설정에서 이름을 바꾸면 그 사람 기록으로 전환됩니다.
브라우저를 바꾸거나 사이트 데이터를 지우면 사라지므로, 가끔 백업 저장으로 파일을 받아두면 안전합니다.
다른 컴퓨터에서 이어서 쓰려면 코드로 옮기기(텍스트 복사·붙여넣기) 또는 백업 저장 → 백업 불러오기(파일)를 이용하세요.
